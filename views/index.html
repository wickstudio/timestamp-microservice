UTILITY API / 01

Clockwork timestamp service.

Turn a valid date or Unix timestamp into a dependable JSON response. No keys, accounts, or configuration required.

Get the current timestamp →

ENDPOINT

Make a request

GET/api/:date?

Use an ISO-style date or a Unix timestamp in milliseconds. Leave the date out to receive the current time.

DATE STRING /api/2015-12-25 ↗ UNIX MILLISECONDS /api/1451001600000 ↗

RESPONSE

{
  "unix": 1451001600000,
  "utc": "Fri, 25 Dec 2015 00:00:00 GMT"
}
